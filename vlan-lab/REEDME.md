VLAN Configuration Lab
## Objective
Configure two VLANS and verify communication between devices in the same VLAN.
## Skills Demonstrated
- creating VLANs 
- Assigning switch ports
- Verifying VLAN membership
- Testing connectivity with ping 
## Tools 
- Cisco Packet Tracer
- Cisco IOS CLI
## Result 
successfully configured VL|ANs and verified connectivity through testing.
