# SSH Configuration Lab

## Overview

This lab demonstrates the configuration of Secure Shell (SSH) for secure remote management of a Cisco router using Cisco Packet Tracer.

## Objectives

- Configure a router hostname
- Configure a domain name
- Create a local user account
- Generate RSA keys
- Enable SSH version 2
- Configure VTY lines for remote access
- Restrict remote access to SSH

## Technologies

- Cisco Packet Tracer
- Cisco IOS CLI
- SSH
- RSA
- IPv4

## Skills Demonstrated

- Secure remote device administration
- Cisco IOS configuration
- SSH configuration
- User authentication
- Network troubleshooting

## Testing

The router and PC were successfully connected and connectivity was verified using ping.

SSH remote-login testing was limited by the Packet Tracer/IOS environment used for this lab.
