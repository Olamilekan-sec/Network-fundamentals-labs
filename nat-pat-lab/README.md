# NAT and PAT Configuration Lab

## Overview

This lab demonstrates the configuration of Network Address Translation (NAT) and Port Address Translation (PAT) using Cisco Packet Tracer.

## Objectives

- Configure static NAT
- Configure PAT
- Configure inside and outside interfaces
- Configure routing between networks
- Verify connectivity
- Troubleshoot NAT configuration

## Technologies

- Cisco Packet Tracer
- Cisco IOS CLI
- NAT
- PAT
- Static Routing

## Skills Demonstrated

- Network Address Translation
- Port Address Translation
- Router configuration
- IP addressing
- Network troubleshooting
