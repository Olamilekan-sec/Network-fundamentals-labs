# Router-on-a-Stick with VLANs and Port Security

## Overview

This lab demonstrates how to configure inter-VLAN routing using Router-on-a-Stick while implementing VLAN segmentation and switch port security.

## Technologies

- Cisco Packet Tracer
- Cisco IOS CLI
- VLANs
- Router-on-a-Stick
- Port Security

## Objectives

- Create VLAN 10 and VLAN 20
- Configure switch ports
- Configure trunking
- Configure router subinterfaces
- Enable port security
- Verify connectivity using ping

## Network Topology

The network consists of:
- 1 Cisco ISR Router
- 1 Cisco 2960 Switch
- 1 PC (VLAN 10)
- 1 Laptop (VLAN 20)

## Skills Demonstrated

- VLAN configuration
- Trunk configuration
- Inter-VLAN routing
- Port security
- Network troubleshooting
